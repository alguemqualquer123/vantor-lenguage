# Lexicon Language Support

Visual Studio Code extension for the Lexicon programming language.

## Features

- Syntax highlighting for `.lex` files.
- IntelliSense support.
- Lexicon Dark Pro and Midnight themes.
- Custom file icons.

## Installation

1. Download the `.vsix` file.
2. Run `code --install-extension lexicon-lang-0.1.0.vsix` or use the "Install from VSIX..." command in VS Code.
