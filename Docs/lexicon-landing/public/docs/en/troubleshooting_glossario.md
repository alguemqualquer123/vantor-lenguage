# Troubleshooting

Common issues and how to fix them.

## 1. Common Issues

### 'lex' command not recognized
Verify that the `bin` directory is in your `PATH`. Restart your terminal after installation.

### Cross-Compilation Error
Define the `LEXICON_TARGET` environment variable correctly before running the build.

## 2. Glossary

- **FFI (Foreign Function Interface)**: Mechanism to call native C/Rust functions.
- **WASM (WebAssembly)**: Binary format for native execution in the browser.
- **Pipe Operator (|>)**: Operator for functional data transformation chaining.
- **Null-Safe Navigation (?. / ??)**: Safe access and nullish coalescing.
- **Hot Reload**: Live code updates without application restart.
