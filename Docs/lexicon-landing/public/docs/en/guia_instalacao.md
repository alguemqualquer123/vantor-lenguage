# Installation and Setup

Get started with Lexicon in seconds on any operating system.

## 1. Automatic Installation

### Windows
```powershell
iwr get.lexicon.dev/install.ps1 | iex
```

### Linux/macOS
```bash
curl -fsSL get.lexicon.dev | sh
```

## 2. Manual Installation

1. Download the SDK from the [Portal](https://lexicon.dev).
2. Extract the archive.
3. Add the `bin` folder to your `PATH`.

## 3. IDE Support

We recommend using the **Lexicon Language Support** extension for VS Code to get:
- Syntax highlighting
- IntelliSense
- Animated cursors
- Custom file icons
